BotPlatform 管理面板功能介绍与使用指南

概览

BotPlatform 是一套多租户智能体机器人平台。本管理面板用于配置模型、智能体、工具、定时任务，查看会话，并管理接入机器人的终端用户与面板管理员账号。左侧导航对应各功能模块，下面逐一说明。

登录与账号

  • 面板通过账号 + 密码登录，登录后使用会话 Cookie 维持状态；点击左下角退出按钮可注销。
  • 首次启动会自动创建管理员账号 admin，初始密码打印在启动日志，并保存在 data/system/admin_initial_password，请登录后尽快修改。
  • 不同账号按角色拥有不同权限，界面会依据权限自动隐藏无权访问的入口。

功能模块

对话

与智能体进行多轮对话调试。可新建/切换/删除会话，支持流式输出、工具调用轨迹展示；可查看历史消息。用于验证智能体配置与效果。

模型

管理可用的模型档案（新增、编辑、启用/禁用、切换主模型）。密钥不在此填写，需写入 data/system/model.env；远程模型地址须为 HTTPS，仅本机回环可用 HTTP。

智能体

创建与编辑智能体：设置名称、系统提示词、可用工具、技能与 MCP 服务等。智能体的可用工具 = 内置工具 + 插件工具 + 已授权的 MCP 工具。

工具

包含多个子项：

  • 内置工具：文件读写、命令执行、脚本运行等本机能力，可单独启用/停用与设置是否需要审批。
  • 插件工具：由已安装且启用的插件提供，并需为智能体显式绑定。
  • Skill 技能：注入到系统提示的提示片段。
  • MCP 服务：接入的 MCP 服务器及其工具，可在线调试。
  • 运维脚本：集中管理受信任脚本，并追踪每次执行状态与日志。
  • 执行审计：记录工具状态、耗时和错误，便于安全追踪、排查与合规；模型 Token 与成本在“模型 → 用量与成本”中独立统计。

知识库

按公共或私有范围管理业务知识，并将知识分类授权给智能体使用。

文件库

管理公共文件区与租户独立文件区，支持文件夹、上传下载、预览、移动和操作审计。

消息渠道

查看已接入的机器人渠道（如微信 iLink）的连接状态。

定时任务

管理 cron 定时任务，支持文本、智能体生成、脚本执行、插件调用等动作。修改后自动重载调度，无需重启。

成员、组织与平台治理

  • 成员与设置：所有成员可协作维护组织资源；Owner/Admin 负责凭据、成员、预算和组织生命周期。
  • 组织管理：平台管理员维护组织及存量个人空间，接入身份和历史机器人身份在组织详情中统一展示。
  • 管理员账号：新建/编辑/停用/删除面板管理员，并为其分配角色；新账号初始密码为 12345，可用"重置密码"生成随机新密码。
  • 角色权限：查看与编辑各角色的权限（点击角色行弹窗编辑）；内置 admin 角色拥有全部权限且不可修改。

环境变量、组织变量与集成凭据

部分运维脚本、插件与定时任务在运行时需要外部配置（如服务地址、超时、特性开关）。平台把“声明变量”和“填值”分开，并提供两层变量 + 集成凭据机制：

  • 声明（作者侧）：脚本作者在 src/core/jobs/<目录>/script.json 的 env_allowlist、插件作者在 plugin.json 的 env_allowlist 中声明所需变量名（大写字母/数字/下划线，每行一个）。声明后，对应弹窗才会展示这些变量的“绑定”情况。
  • 填值（平台 / 组织侧）：变量值不在脚本/插件弹窗内编辑，而是填在两处——全局环境变量（平台统一维护，与 model.env 同一套全局机制）与组织变量（在「组织管理」组织/租户详情页的“组织环境变量”卡片中按组织填写，存于组织数据库 tenant_env 表，明文存于权限 0600 的 SQLite，适合按组织区分的非敏感配置）。
  • 运行时合并：对脚本/插件声明的变量名，运行时优先使用组织变量值，覆盖全局环境变量值（组织 > 全局）。脚本以独立子进程运行，环境按白名单重建、不继承进程环境；插件在进程内运行，经 PluginContext.env() 注入，避免跨租户泄漏。
  • 保留名保护：PATH、HOME、LANG、AUTOGEN_ENV_FILE 等系统变量，以及 ILINKBOT_ 等运行时注入前缀被禁止声明，避免污染或越权。
  • 敏感凭据走集成凭据：账户、密码等通过 /integration setup <ctsehr|ctsoa|autogen> 配置，密文只存于权限 0600 的受限凭据文件，任何列表/详情/日志都不会返回明文。不要把密码塞进组织环境变量。在“执行脚本”与“新建/编辑脚本计划”弹窗中，会直接显示所选脚本的集成凭据（账户 + 密钥链）是否就绪；未配置时明确提示先执行 /integration setup。

常见问题

  • 改了配置文件没生效？ 平台目录以数据库为准；config/*.json 只用于首次导入。请通过管理页面直接保存配置。
  • 哪些发布需要重启？ 嵌入/重排模型、插件包和脚本代码会显示“等待重启”；其他支持热切换的资源发布失败时仍使用旧运行版本。
  • 如何切换组织？ 仅组织页面在页头显示选择器，选择结果写入当前 URL。平台页面没有组织上下文，也没有全站“当前组织”。
  • 看不到平台治理？ 聚合分析、平台审计和管理员账号只对平台管理员开放。
  • 局域网访问不了？ 启动时需指定 --host 0.0.0.0 才能被其他机器访问。
